## P0 · 安全与崩溃，必测

### 1. Ink 档重启不崩 ✅ 已验

设置切到 Ink → **完全退出应用**（不是关窗口）→ 重启。要正常起来且仍是 Ink。

> 背景：Electron 的 `nativeTheme` 只认三档，black 必须映射成 dark，代码注释写的是「启动即崩的坑」。

### 2. 富文本安全闸 ❗风险最高

让 agent 原样输出下面这段（用这个 prompt）：

```text
请把下面这段原样输出成 markdown 代码块外的正文内容，不要解释、不要加代码块包裹，我要测试渲染器：

<script>alert(1)</script>
<img src=x onerror="alert(1)">
<details><summary>点我展开</summary>藏起来的内容</details>
<iframe src="https://example.com"></iframe>
```

**要看的**：

- `<script>` 和 `<img onerror>` 必须显示成**纯文本**，绝不能执行（没有弹窗）
- `<iframe>` 也必须是纯文本
- **只有** `<details>` 应该渲染成真的可折叠块，点击能展开「藏起来的内容」

> 背景：`rehype-raw` 放行原始 HTML，`rehype-sanitize` 的白名单只该放行 `details`/`summary`。
> 两者顺序错了（raw 必须在 sanitize 之前）等于没有 sanitize。

### 3. 图片永不外联

```text
请输出一张图片的 markdown：![测试图](https://httpbin.org/image/png)
另外再输出一个裸链接形式的 <img src="https://httpbin.org/image/png">
```

**要看的**：

- 两种写法都**不能真的加载图片**，应该显示成占位链接芯片
- 点击芯片 → 在**系统浏览器**打开，不在应用内加载
- 断网状态下也不该有任何加载失败的破图标（说明压根没发请求）

> 背景：这刀的目的是「你的 IP 不再被图床静默记录」。

### 4. 对话不黑屏

打开一个**有历史内容的旧会话**，正常渲染即可。

> 背景：`a0d0e75` 修的就是接入 KaTeX 时把整个对话区搞黑屏（unified 插件传了调用结果而不是工厂本身）。
> 这是回归检查，不黑屏就过。

## P1 · 渲染正确性

### 5. 数学公式（KaTeX）

```text
请原样输出下面五行，不要解释：

行内公式测试：质能方程 $E = mc^2$ 混在文字中间。
块级公式测试：$$\int_0^1 x^2 \, dx = \frac{1}{3}$$
金额测试：这个套餐卖 $5 and $10 两个价位。
错误公式测试：$\notacommand{x}$
希腊字母：$\alpha + \beta = \gamma$
```

**要看的**：

- 行内公式跟正文同一行，不换行不撑高
- **块级公式居中**
- **`$5 and $10` 绝对不能被当成公式渲染**——remark-math 实测会把它误判，作者专门加了防护
- 错误公式显示成**斜体次级灰的源码**，不是红色报警
- 公式颜色跟随主题（切到 Light 看一眼）

**流式成形**（单独一条）：

```text
请慢慢地、分多段输出一个较长的 LaTeX 公式推导，每段之间自然停顿，我要观察流式渲染过程。
用 $$...$$ 包裹至少三个不同的公式。
```

要看的：输出过程中公式**逐步成形**，不是先烂一片再突然变好。未闭合的瞬间显示灰色源码是正常的。

**离线可用**（关键）：

断开网络 → 重开应用 → 让它输出一个公式（或翻旧会话里的公式）。
**字体必须仍然正常**，不能变成方框或衬线回退——katex 字体应该是本地打包的。

### 6. 机器内容用色（切到 Ink 或 Warm 看）

```text
请输出一段 TypeScript 代码块，里面要包含：函数定义、函数调用、字符串、注释。
然后在正文里用行内代码提到 `src/main/index.ts` 这个文件路径和 `bun run dev` 这个命令。
```

**要看的**：

- 代码块里的**函数调用位**（`foo()` 这种）是**亮紫色**——以前只有函数声明是紫的、调用跟正文同色
- 正文里的行内 `` `代码` `` 是**链接蓝 `#52a8ff`**，不是正文墨色
- 代码块有 **1px 发丝线边界**（深色下代码块底色和地面只差几阶，没有边界会糊在一起）
- 让它读一个文件，工具行里的**文件路径也应该是链接色**
- **浅色主题下这些都不该变**（这刀只动深色）

## P2 · 主题与视觉

### 7. 四档主题切换

设置里把 Light / Warm / Ink / System 都点一遍。

- **Ink**：页面 `#0a0a0a`、卡片 `#111111`（极暗中性，vercel 味），墨 `#ededed`/`#a1a1a1`
- **Warm**：地面 `#191c1d`/`#232525`，只带一丝暖，**黄色选中底只有 5%**（选中主要靠字重和文字色，不靠黄底）
- 两档的**玻璃质感**应该同配方，代码高亮跟着翻色

### 8. System 的深色落点是 Ink

把 macOS 系统外观切成深色 → 应用应该变成 **Ink**（不是 Warm）。
切回浅色 → 变 Light。

> 这是产品决定，确认你认可。Warm 只能手动选。

### 9. 老设置迁移

你原来存的主题偏好如果是 `dark`，现在设置面板里应该显示为 **Warm**，且**不需要重新设置**。

> 如果你的配置文件已经被这几轮测试覆盖过，这项可能测不了，跳过即可。

### 10. 主题切换过渡

Light ↔ Ink 来回切几次：应该是**整窗交叉淡入**，不瞬跳、不闪帧。

然后打开 macOS「系统设置 → 辅助功能 → 显示 → 减少动态效果」，再切一次：
应该**即时切换、没有动画**。

### 11. 折叠卡与导轨（在 Ink 下看最明显）

让 agent 做一个会调用多个工具的任务，例如：

```text
读一下 src/main 目录下的三个文件，每个用一句话说明职责。只读不改。
```

**要看的**：

- 展开工具行，**纵向导轨与 icon 左缘相切**（x=10px），正文在竖线右侧，不越过图标左缘
- 组行成员与组头**同左缘**，折叠行 icon 上下对齐
- 导轨在 Ink 下**看得见**（`subtle` 竖线在 `#1e1e1e` 对 `#0a0a0a` 下不可见，作者升成了 `border-default`）
- 文案全英文：`Read` / `Run` / `Search` / `Write` / `Edit` / `List`、`Thinking` + `3s`、`Running` / `Failed` / `No output`
- bash 组头显示**真实工具名**，不是笼统的 `Run`

**压缩界碑**（需要触发一次上下文压缩，或翻一个压缩过的旧会话）：

- 压缩卡应该和工具行**同款骨架**：满宽 32px 热区、悬停淡底、圆角裁边
- 折叠头是两段式：`Compacted` + 右侧等宽数字 `128,000 → 8,200 tokens`
- 上方保留一条 hairline 分割线（那是「分段」的语义标记）

**首页 slogan**「璇玑运转，诸事得序」**保持中文**——全产品唯一保留的中文界面文案。

## 已知的两个遗留问题（不属于本分支，别当 bug 报）

1. **`src/agent/**` 不在任何 tsconfig 的 include 里**——整个 agent utility 进程是类型检查盲区。
   加进去会暴露 15 处历史错误，多数在 `transcript-adapter.ts`（`pi-protocol` 有两份互不相关的类型副本）。
   建议单独立项，优先级高——它是「下一个同类 bug」的温床。
2. **`createSessionRecorder` 里「用户消息走 item_started 落盘」这个测试是 flaky 的**，
   涉及文件 IO 计时。遇到偶发红灯重跑一次即可。
