Small status or metadata label — words first, colour only when the state matters.

```jsx
<Badge variant="accent">steer</Badge>
<Badge mono>a7f3c1</Badge>
```

`secondary`/`muted` for neutral facts, `outline` for hairline chips, `accent` for the delivered/primary state, `info` for follow-up. Never stack more than one coloured badge in a row.
