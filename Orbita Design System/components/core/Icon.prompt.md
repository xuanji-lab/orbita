Inlines one of the project's copied Lucide SVGs so it takes `currentColor` — use it anywhere an icon appears.

```jsx
<Icon name="arrow-up" size={16} strokeWidth={2} />
```

Set `window.ORBITA_ICON_BASE` once per page when the icon folder is not at `assets/icons/lucide` relative to the document. Sizes in the product: 12 in sidebar tree rows, 13–14 in chips and list rows, 16 in the rail and headers.
