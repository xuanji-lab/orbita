# 僧道录司与宗教管理

## 明代的宗教管理体系

明代对宗教实行**严格的国家管控**。佛教和道教被承认合法，但被纳入国家行政体系管理——寺庙不能自行运作，宗教领袖需要朝廷认证。

| 机构 | 长官 | 品级 | 职能 |
|:--|:--|:--|:--|
| **僧录司** | 正印/副印(僧官) | 正六品 | 管理全国佛教事务 |
| **道录司** | 正印/副印(道官) | 正六品 | 管理全国道教事务 |

僧道录司不是独立的宗教组织，而是**礼部下属的行政机构**。僧录司的僧官由礼部从全国高僧中选拔、皇帝任命——不是由佛教界自行产生。

## 度牒制度

所有僧尼必须持有朝廷颁发的**度牒**（僧人身份证），无度牒者即为"私度"，违法。度牒的数量受到严格控制——朝廷定期开放度牒考试，考取者获得合法身份。这个制度确保了：
- 出家当僧尼的人数是可控的（太多人出家导致劳动力减少和税基缩小）
- 僧尼的素质和佛学知识有最低标准
- 朝廷掌握全国僧尼的数据

## 对编排系统的启发

僧道录司的**"用行政手段管理思想领域"**是明代非常有特色的制度设计。在编排系统中，一个类似的逻辑是律例 Agent 对规则库的管理——规则库是编排系统的"思想领域"，但它不是自由生长而是由律例 Agent 严格维护、修订需批红、改动有冷却期。

## 编排参考

- "度牒制度" → **预算账户的开设审批**：不是任何 Agent 都可以随意消耗 Token，必须由太仓库开户(度牒)才能从对应预算账户支取——控制了"谁能消耗资源"
- "僧道录司隶属于礼部" → **律例 Agent 不是独立权力**：僧道录司管理宗教但隶属于礼部 → 律例 Agent 维护规则库但规则修订必须经总控批红——规则管理者不是规则制定者
