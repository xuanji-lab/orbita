## 政府与行政

| 批红 | Imperial endorsement (pi hong) | 总控 Agent 最终确认 | 皇帝用红笔在票拟上批写最终决定 |

| 再议 | Send back for revision | 用户批"再议" | 皇帝不满意票拟时退回要求重新讨论 |
| 中旨 | Direct imperial decree | 总控不经内阁的直接指令 | 皇帝不经内阁和六科直接下发的命令 |
