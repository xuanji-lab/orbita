## 5 分钟读懂明朝官制

**一句话**：明代用**分权互锁**取代单一命令链——一件事拆给多个互不统属的部门协作，任何一方都无法独揽大权。

**五链路架构**（记住这 5 条链就够）：

```
决策链：皇帝(批红) → 内阁(票拟) → 司礼监(代批)
    ↓
执行链：六部(吏户礼兵刑工) → 地方三司 → 军事(总督/巡抚/总兵)
    ↓
监察链：六科(封驳) + 都察院(弹劾) + 大理寺(复核) + 厂卫(元监察)
    ↓ (贯穿全链)
信息链：通政司(入口) → 奏章流转 → 塘报(军情) → 邸报(广播)
    ↓ (贯穿全链)
资源链：户部(财政) → 考功(考核) → 科举(选拔) → 黄册(数据)
```

**最关键的 10 个术语**：

| 术语 | 一句话 |
|:--|:--|
| **票拟** | 内阁在奏章上写处理建议 |
| **批红** | 皇帝用红笔批准票拟，使之生效 |
| **封驳** | 六科给事中驳回不合程序的诏旨 |
| **会推/会审/转行/关白** | 六部之间的四种横向协同方式 |
| **考成法** | 张居正的问责制——任务绑定负责人/时限/验收标准 |
| **诏狱** | 锦衣卫独立监狱，皇帝直控 |
| **厂卫互监** | 东厂监察锦衣卫，锦衣卫反监东厂 |
| **总督/巡抚** | 跨省/一省的差遣统帅（本职+差遣分离） |
| **首功制** | 按斩获首级计功——竞功模式的源头 |
| **选锋** | 基于历史表现的精锐标签（含时效衰减） |
