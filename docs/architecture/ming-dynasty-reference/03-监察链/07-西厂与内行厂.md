# 西厂与内行厂

## 西厂的设立与兴废

西厂由明宪宗成化十三年（1477年）设立，由宦官汪直掌管。设立的直接原因是京城出现"妖狐夜出"的恐慌事件，宪宗怀疑有反叛势力暗中活动，而东厂和锦衣卫都查不出线索（也可能是查出来不敢报）。于是增设西厂，让汪直直接调查。

**西厂的特点**：
- 权力比东厂更大，行动更不受限制
- 汪直可以直接逮捕四品以下官员（东厂没有逮捕权）
- 侦查范围从京城扩大到全国各省
- 行事极其高调残忍，大量制造冤案

**西厂的废除**：汪直权力膨胀到威胁皇权本身时，宪宗于成化十八年（1482年）突然将他贬到南京，西厂随之废除。此后在明武宗正德年间由刘瑾短暂复设，刘瑾倒台后再废。西厂总共存在了不到10年。

## 内行厂（刘瑾特设）

刘瑾在掌管西厂的同时，又设了一个**内行厂**（正德三年，1508年），专门监视东厂和西厂——也就是说他连自己掌握的西厂都不放心，又建了一层监视来确保无人敢背叛。

内行厂的可怕之处：东厂和西厂调查别人，内行厂调查东厂和西厂。刘瑾通过三层特务体系确保对他的绝对忠诚。但这恰恰引发了他的覆灭——体系太恐怖，所有人都想让他死。

## 西厂/内行厂的教训

西厂和内行厂的存在证明了：**特务机构的数量不等于控制力，超过上限后反而催生系统性的反噬**。东厂+锦衣卫（厂卫互监）足以维持皇权的信息优势。再加西厂和内行厂，不仅没有获得更多高质量情报，反而让整个官僚体系因恐惧而瘫痪——没有人敢做决策，因为任何一个决策可能已被某层特务记录在案。

这也是为什么明代正常运转时（仁宣之治、嘉靖中兴、万历初期）特务体系维持在东厂+锦衣卫两层的平衡状态，西厂和内行厂只在皇帝个人极端多疑且宠信某个宦官时短暂出现。

## 编排参考

任事型编排系统提到了西厂但仅做了位置预留（"待补充"），这是一个自觉的设计选择：
- 编排系统保留了东厂（元监察）和锦衣卫（诏狱隔离）的厂卫互监两层结构
- 没有设计对应"西厂"的第三层——因为两层已经足够覆盖监察需求，第三层只会造成系统性恐惧和内耗
- 西厂的教训直接对应编排系统中的**防振荡约束**：如果监察层太多，每一层都为了证明自己"有存在价值"而过度弹劾，系统会陷入监察僵化

核心洞察：西厂的短暂历史证明了**监察体系存在最优层数**——太少（没有独立监察）则失控，太多（多层互相监视）则瘫痪。编排系统中的两层监察（监督+审计是一层，东厂元监察是第二层）正是对这个平衡点的工程判断。
