## 常规奏章 vs 密奏

明代存在两条平行的信息通道：

| | 常规奏章 | 密奏（密疏） |
|:--|:--|:--|
| **通道** | 通政司 → 内阁票拟 → 皇帝批红 | 直接呈交皇帝，不经任何中间环节 |
| **使用者** | 所有官员 | 只有授权者（监军御史、东厂、锦衣卫、钦差等） |
| **可见性** | 内阁和六科都能看到 | 只有皇帝本人能看到 |
| **格式** | 标准公文格式，存档公开 | 格式自由，密封蜡封 |

密奏制度让皇帝获得了绕过整个官僚体系的信息渠道。

## 监军密奏

外派到军队的监军御史有权发密奏，内容可包括：
- 某将领谎报战功
- 军队实际状况与公开塘报不符
- 军饷被贪污克扣的证据
- 某将领与地方势力勾结

密奏之所以能进，是因为监军御史的弹劾不经过内阁、不经过兵部、不经过都察院——直接到皇帝手里。被弹劾的人在听到风声之前，皇帝的调查令可能已经发出了。

## 密奏的限制

- **频次上限**：不能天天发密奏（频繁密奏会被视为"妄议"或"越权"，皇帝也会厌烦）
- **内容必须可核实**：如果密奏内容事后被证明是捏造，发密奏者反坐（受到同样惩罚）
- **不是写小报告**：密奏是针对系统性问题的预警，不是针对个人恩怨的泄愤工具

## 密奏与常规系统的关系

密奏不取代常规监察体系——都察院的弹劾、六科的封驳、审计的事后审查仍然有效。密奏是常规体系的**补充**而非替代：当常规体系因利益关联、信息封锁、或流程延迟而失效时，密奏提供了一条快速直达最高决策者的通道。

## 密奏的授权体系：谁有资格发密奏

不是所有官员都能发密奏——密奏权是一种**特授**，不是职务自带的：
- **监军御史**：随军外派时自动获得密奏权——任期结束即收回
- **东厂督公**：终身密奏权——但密奏内容仅限于监察相关
- **锦衣卫指挥使**：终身密奏权——与东厂互监的内容必须通过密奏
- **钦差大臣**：任务期间获得密奏权——但密奏范围限于任务相关的"非常事件"
- **地方督抚（后期）**：正德以后总督和巡抚逐渐获得密奏权——用于报告"不宜通过常规公文"的敏感信息

未经授权的人发密奏——擅自密封奏章绕过通政司——被视为"越权"和"僭越"。轻则严斥、重则降职。这保证了密奏通道不被滥用——如果任何人都能发密奏，密奏通道就失去了"绕过常规信息过滤"的意义，变成另一个常规通道。

## 密奏的加密机制与存档

密奏的物理安全性通过多重措施保障：
- **密封蜡封**：发密奏者在奏章外加封套，以火漆蜡封，加盖个人印章。任何拆封痕迹立即可见
- **专人传递**：密奏不由常规驿传递送——监军密奏由随从专骑直达京城、东厂密奏由厂役专递
- **直达皇帝**：密奏送达京城后不经通政司——直接交司礼监掌印太监转呈皇帝。中间环节为0
- **皇帝亲启**：原则上皇帝应该亲自拆封阅读密奏（后期怠政时由掌印太监代拆，但掌印太监不能批答）
- **密奏存档的特殊规则**：密奏正本存入皇史宬的"密档区"——与常规档案分库保存。调阅密奏档案需要皇帝亲批（内阁和六科无权调阅任何密奏原件）

但密奏存档也有其自反性缺陷——**密奏一旦存档，其内容最终可能被后人调阅**。所以写密奏的人会自我审查——不会在密奏中写"皇帝您做错了"之类的话。这是密奏与常规公文的微妙差异：常规公文存档也不怕看，密奏存档后一旦公开就可能引起政治风暴。

## 密奏的真实性验证

密奏最大的风险是**信息失真**——绕过了所有中间核查环节，直接到皇帝手里的信息也可能是错的：
- 发密奏者可能故意夸大或隐瞒
- 发密奏者可能被人利用传递假信息
- 密奏中的"数据"缺乏交叉比对（常规奏章有内阁和六科把关，密奏没有）

明代的防范机制：
- **密奏实名制**：每一份密奏都署实名——匿名举报的密奏被视为无效
- **事后核查**：密奏内容被采纳并采取行动后，常规监察体系（都察院/六科）会事后验证密奏的真实性
- **反坐制度**：若密奏被证实为诬告——发密奏者受到同等甚至更重的惩罚。包括东厂督公也不例外（刘瑾被诛就是东厂内部密奏被另一个密奏反坐的结果）

## 密奏与常规信息系统的协同关系

密奏不是替代常规监察——两者是并行且互为补充的：

| 场景 | 常规通道 | 密奏通道 |
|:--|:--|:--|
| **日常监督** | 都察院弹劾、六科封驳 | 不适用——密奏不用于日常 |
| **系统性偏转** | 可能无法发现（因为层层过滤） | 适用——密奏是最后防线 |
| **紧急预警** | 奏章流程数天到数周 | 密奏2-5天直达 |
| **诬告误判** | 内阁和六科可纠错 | 无人可纠正——只能事后反坐 |
| **政治操纵** | 多层把关——难以操纵 | 皇帝单信道——可被操纵 |

核心洞察：密奏的价值和风险来自同一根源——**绕过所有中间层**。绕过中间层可以突破信息封锁，但也意味着失去了所有中间层的校验。所以密奏的使用必须有严格的授权、频次限制和事后反坐制度——否则它就是整个信息系统中最大的脆弱点。

## 编排参考

任事型编排系统中有两条独立的密奏模拟：
- "监军密奏通道" → 监军御史发现系统性偏转时直接向总控发送预警摘要，不经过总督或常规监察链
- "东厂密奏" → 东厂 Agent 的密奏专线直通总控，不经司礼监代批，可弹劾任何 Agent
- "密奏频次上限" → 由律例设定，超限触发审计审查——防止密奏被滥用
- "密奏预警触发诏狱" → 密奏预警被证实严重者可建议总控启动诏狱
- "密奏反坐" → 虚假密奏一经查实，发密奏者权重永久降低——对应反坐制度
- "密奏授权列表" → 律例 Agent 维护可发密奏的 Agent 清单——对应密奏的特授原则

核心洞察：密奏制度解决的是**信息过滤问题**——在层级组织中每一层都可能对上报信息进行"美化"（坏消息层层过滤），最高决策者最终收到的信息可能严重失真。密奏绕开所有中间层，保留了至少一条"未经加工"的信息通道。但编排系统必须平衡密奏的好处和单信道风险——所以密奏频次有上限、内容事后可审计、虚假密奏触发反坐。
