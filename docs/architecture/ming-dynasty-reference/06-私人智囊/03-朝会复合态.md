# 朝会复合态

> 从廷议与朝会拆出。朝会辩论规则如何映射到谋士型编排的多Agent协同。
## 朝会调论规则的设计启示

| 明代机制 | 编排对应 | 设计价值 |
|:--|:--|:--|
| **低品级后发言** | 门客先发言→帝皇后发言 | 避免高权重Agent意见压制低权重Agent |
| **言官最后发言** | 谏院御史最后发表反对 | 专门挑刺角色需要看到所有意见 |
| **不投票只议事** | 朝会复合态不投票 | 决策权始终在用户/总控 |
| **多轮廷议** | 三轮调论（发散→量化→批驳） | 每轮焦点不同，避免在同一点纠缠 |
| **风闻言事** | 谏院御史可提疑虑不需实错 | 宁可多查不能放过 |
| **留档官意** | 调论过程全部归档 | 后续问责依据 |

**避免的失灵模式**：
- 避免大礼议式失灵：总控不能完全忽视Agent意见独断（要有反馈）
- 避免国本之争式失灵：议题不能无限拖延，必须有超时机制
- 避免党争式失灵：Agent不能形成固定派系，需要轮换和多样性
