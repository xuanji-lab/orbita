# 基层社会组织

> 知县的下面是怎样运作的？本文档覆盖县级以下的基层社会组织——里甲、粮长、乡约保甲，以及"皇权不下县"的真实含义。

## "皇权不下县"——但不是"无人管"

明代正式行政体系的末端是**知县**（正七品）——全国约1171个县，每个知县管理数万到数十万百姓。知县以下的里甲、粮长、乡约等组织**没有朝廷品级**，不是正式命官——但它们构成了整个赋税体系和社会秩序的毛细血管。

**关键区分**：
- "皇权不下县"意味着朝廷没有在县级以下任命官员——但不意味着县级以下没有组织和权力
- 县以下的权力掌握在三种力量手中：**里甲（行政系统的延伸）、士绅（社会精英）、宗族（血缘组织）**

## 一、里甲制度——赋税体系的末端

### 编制

洪武十四年（1381年），朱元璋在全国推行里甲制度：

```
110户 = 1里
  ├── 10户丁粮最多的家庭 = 里长户（每年一户轮流做里长）
  └── 其余100户 = 甲首户（分10甲、每甲10户）
```

**里长的职责**（每年轮换一次，十年一轮）：
- **征税**：向本里110户收缴赋税（这是最核心的职能）
- **派役**：分配本里的徭役任务（谁去修河、谁去守城）
- **编制黄册**：每十年配合衙门重编本里的人口和土地登记
- **治安**：报告本里的人口流动和可疑人物
- **调解纠纷**：小事在里内调解、大事上报知县

### 里长的两难

里长不是朝廷命官——没有俸禄，但承担了巨大的责任：

- **完不成税收任务 → 自己垫付**（这是最残酷的设计——如果本里有逃亡户或贫困户交不出税，里长得用自己的家产垫付差额）
- **税太重逼反百姓 → 自己背锅**（知县会说是里长催科无方）
- **大户和胥吏勾结瞒报田产 → 本里的总税额不变 → 贫穷小户和里长分摊了实际上不属于他们的税**

**里长的演变**：明初里长由殷实大户担任（朱元璋的意图是"有产者负责"），有社会地位。到明中后期，里长变成了一种人人避之不及的负担——大户通过各种手段（贿赂胥吏、转移户籍）逃避里长轮值，中下户被迫承担但根本无力垫付。

## 二、粮长制度——朱元璋的得意之作及其异化

### 明初设计

粮长是朱元璋在江南和北方部分省份设立的**税收中间层**。每县按税粮多少设若干粮区（每区约征粮万石），每区设粮长一人：

**粮长的职责**：
- 从本区各里甲收齐税粮
- 组织运输（由粮长雇船或车把粮食运到指定仓库——京城的京仓或边镇的边仓）
- 对运输过程中的损耗和延期负责

**朱元璋的意图**：用民间大户（粮长）来取代衙门胥吏收税——朱元璋认为大户比胥吏更"可信"（有家业在本地、不敢乱来）。对粮长的奖励是：干得好的粮长可以**直接授予官职**——这是平民进入官僚体系的"快速通道"。

### 粮长的异化

到明中后期，粮长从"荣誉+通道"变成了"灾难"：

- **运输成本爆炸**：从江南运粮到北京（漕运）或边镇的路上损耗巨大——粮长得自己掏钱补
- **大户逃避**：大户通过贿赂胥吏把自己的田产"分数"（拆成多户）——逃避粮长轮值资格
- **中下户被迫担任**：最后当粮长的不是"殷实大户"而是"勉强有饭吃但无力承担的"中下户——一轮到粮长就可能倾家荡产
- **粮长成为一种惩罚**：这和朱元璋的初衷完全相反

## 三、士绅——县级以下的真正权力

### 谁是士绅

士绅不是正式职位，而是一种**社会身份**：
- 退休或丁忧（守丧）在家的官员
- 取得了功名但未任官的举人、监生
- 在本地有影响力和土地的大家族长者

### 士绅的权力

| 权力来源 | 机制 |
|:--|:--|:--|
| **与官员同级的社会地位** | 退休官员/举人出身与知县同级甚至更高——知县得对他们客气 |
| **免税特权** | 举人以上功名免除部分赋税和徭役——大批小户把田产"投献"（挂名）到士绅名下以避税 |
| **信息中介** | 士绅是知县了解本地情况的唯一信息渠道——知县被士绅提供的信息框定 |
| **宗族势力** | 士绅通常是本地大宗族的领袖——控制了宗族就控制了基层人力资源 |
| **舆论权力** | 知县如果得罪本地士绅，士绅可以通过在京城的同年、座师弹劾知县 |

### "知县与士绅的共治"

在大多数县的实际运作中，知县不能单方面推行政策——他需要士绅的配合。如果士绅抵制（不出力、不配合征税、不提供信息），知县什么事也做不成。所以绝大多数知县到任后的第一件事不是"做事"而是**拜会当地士绅**——建立合作关系。

## 四、宗族——基层的自治组织

在南方（特别是福建、广东、江西），宗族是基层社会的基本单元。一个村子通常是一个或几个宗族的聚居地。

宗族的组织：
- **族长**（辈分最高或最有威望的长者）
- **族谱**（类似黄册——记载本族所有人的出生/婚姻/死亡）
- **族规**（内部规范——从财产继承到男女关系的规则）
- **族产**（族田——全族共有的田地，收入用于祭祖、助学、救济本族贫户）

宗族在基层的功能：
- 调解内部纠纷（大部分纠纷在宗族内部解决了，不报到衙门）
- 组织生产协作（灌溉、收割期间的互助）
- 基层安保（宗族青年组成的巡逻队）
- 对本族成员的道德约束

宗族与朝廷的关系是微妙的——它是基层秩序的维护者（减少了衙门的工作量），但也是朝廷权力无法深入的屏障（宗族内部的"族规"可能凌驾于《大明律》之上）。

## 五、乡约与保甲——王阳明的基层治理实验

### 乡约

正德年间，王阳明在江西推行"南赣乡约"。其核心设计：

- 每约设约长一人（由本地德高望重者担任，不是朝廷任命）
- 约众定期集会——公开表扬善行、批评恶行
- 记录在册——"彰善簿"和"纠过簿"
- 纠纷先在乡约中调解解决，调解失败再上报衙门

乡约的本质是用**道德和舆论**替代**刑罚和行政**来维持基层秩序——这是儒家"德治"理想在基层的具体实践。

### 保甲

保甲侧重治安功能——每十家为一牌（互相监督），每十牌为一甲，每十甲为一保：

- 一家犯法，其牌内各家如不举报则连坐
- 各家的人口变动（外出/迁入/陌生人）必须报知甲长
- 保甲有自己的巡逻和自卫力量

乡约（道德教化）+ 保甲（治安联防）= 朝廷在最基层的"软硬两手"。

## 编排参考

- "里长垫付" → **责任人的兜底风险**：编排系统中如果某个子任务负责 Agent 必须"无条件完成或自己承担后果"，就会造成类似里长的"风险堆积"——责任心越强的 Agent 越容易被分配兜底任务，最终被耗尽。应该有明确的"免责上限"
- "大户逃避里长轮值" → **高能力 Agent 逃避高责任任务的机制**：编排系统中的"选锋"（高能力 Agent）可能通过降低自己的考功可见度来逃避被频繁分配高风险任务——需要确保"能力可见 → 责任匹配 → 奖励匹配"的公平循环
- "知县依赖士绅获取信息" → **信息垄断的风险**：总控/总督如果只能通过单一渠道获取底层信息，就会被信息提供者"框定"——密奏（多源并行信息通道）是突破信息垄断的唯一方式
- "宗族内部的族规" → **本地规则与全局规则的冲突**：编排系统中的本地卫所（边缘节点）可能有自己的优化规则——当本地规则与全局律例冲突时，需要有明确的优先级裁决机制
- "乡约的彰善纠过簿" → **公共信用记录**：类似考功册但更细粒度——每次任务协作后的相互评价公开记录，形成 Agent 的长期可信度档案
