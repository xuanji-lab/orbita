# 土司制度

> 西南少数民族地区的"间接统治"——朝廷不派流官直接管理，而是通过世袭土司间接统治。这不是权宜之计，而是一种经过计算的治理模式。

## 土司制度的本质

明代在西南地区（今云南、贵州、四川南部、广西西部、湖广西部）推行土司制度：朝廷承认当地少数民族首领的世袭统治权，封他们为土知府、土知州、土知县（官名前加"土"字以别于流官）。土司在自己的辖区内有权征税、司法、征兵——朝廷不干预其内部事务。

**土司对朝廷的义务**：
- 定期朝贡（象征性地送一些特产）
- 听从朝廷征调（朝廷有军事需要时出兵协助）
- 不反叛、不互相攻击（至少在形式上）

**朝廷对土司的约束**：
- 土司的继承需要朝廷批准（"承袭"——继承人必须得到朝廷的正式任命才算合法）
- 朝廷保留"改土归流"的终极权力（废除土司，改为朝廷任命的流官——但这一般只在土司反叛或绝嗣时启动）

## 为什么要在西南用土司而非流官

| 因素 | 影响 |
|:--|:--|
| **地理** | 山区交通极差（从省城到一个县可能需要走十几天山路）——流官不愿去、去了也管不动 |
| **语言** | 少数民族不通汉语——流官必须通过当地通事（翻译）才能沟通，信息被通事过滤 |
| **习俗** | 少数民族有自己的习惯法和部落结构——强行推行《大明律》会激起叛乱 |
| **成本** | 如果每个县都派流官+驻军+驿站——朝廷对西南的投入将远超其赋税产出（西南的农业税极少） |
| **军事** | 土司有自己的军队（土兵）——与其用朝廷军队去镇压他们，不如收编他们为朝廷所用 |

**务实逻辑**：土司制度的本质是**"承认实际上的统治权，换取名义上的臣服"**——朝廷放弃了对西南的实质性治理，获得了政治上的统一和军事上的协助。这对双方都是可以接受的最低成本方案。

## 土司的类型

| 类型 | 品级 | 代表地区 | 权力 |
|:--|:--|:--|:--|
| **土知府** | 从四品 | 云南多地、贵州播州、四川乌蒙 | 管一府——征税/司法/征兵 |
| **土知州** | 从五品 | 广西西部、云南边境 | 管一州 |
| **土知县** | 正七品 | 零星分布 | 管一县 |
| **宣慰司/宣抚司** | 从三品~正四品 | 云南麓川、贵州水西 | 更偏军事——实质上是半独立的部落联盟 |

> 最大的几个土司辖区（如云南麓川宣慰司、贵州播州宣慰司）面积相当于内地数府甚至一省，拥兵数万——实际是国中之国。

## 土司制度的运作与问题

### 朝廷的控制手段

- **承袭审批**：土司去世后，继承人必须上报朝廷批准——朝廷可以借此干预（选择亲朝廷的继承人、延迟批准迫使各方妥协）
- **分化**："众建诸侯而少其力"——把一个大的土司辖区拆分成多个小的（如将麓川拆成三个宣抚司）
- **教育渗透**：要求土司继承人（"土舍"）到北京国子监读书——培养对朝廷的文化认同
- **军事威慑**：在土司地区的关键位置驻扎卫所（如贵州的二十多个卫）
- **以土制土**：利用土司之间的矛盾，让一方打击另一方（"以夷制夷"）

### 土司的离心力

- 世袭统治使土司把自己的辖区视为"祖业"——对朝廷的服从是有条件的
- 土司之间的战争频繁——朝廷的调解往往无效（因为朝廷在当地的军事力量不足以强制执行）
- 土司地区的经济文化落后——朝廷的文化同化政策收效甚微

### 重大事件

| 事件 | 时间 | 影响 |
|:--|:--|:--|
| **麓川之役** | 正统年间（1436-1449） | 明朝对云南麓川土司发动了四次大规模军事行动——消耗了大量军队和财政（间接导致土木堡之变时北京空虚） |
| **播州之乱** | 万历年间（1590-1600） | 播州宣慰使杨应龙叛乱——万历帝调集四川、贵州、湖广三省兵力平叛，耗银数百万两（"万历三大征"之一） |
| **奢安之乱** | 天启年间（1621-1629） | 贵州水西土司奢崇明和安邦彦叛乱——配合东北的后金形成"南北夹击"之势 |

## 改土归流——从尝试到全面推行

明代已有零星的改土归流（将世袭土司改为朝廷任命的流官），但规模不大。原因是：
- 每次改土归流都伴随着军事行动和镇压——成本极高
- 流官到任后面对的是完全陌生的社会——往往管不了、最后又请回土司的后代
- "土人只知有土司不知有朝廷"——改土归流后税收征不上来、治安反而恶化

真正的改土归流要到清代雍正年间（1726-1735年）才由鄂尔泰大规模推行——到了那时土司制度已经延续了数百年，清廷有更强的国力和决心来完成这一转型。

## 编排参考

- "朝廷承认土司的自治换取名义臣服" → **编排系统的联邦式管理**：对于外部接入的第三方 Agent 或模块，不要求其完全按照内部规则运行——只要它们遵守"接口协议"（朝贡/出兵），内部逻辑可以自治。这降低了集权管理的成本和冲突
- "承袭审批作为控制手段" → **权限传递的审批机制**：编排系统中如果一个 Agent 需要"继承"另一个 Agent 的权限（如替补接管），必须通过总控或司礼监的审批——这防止了权限在 Agent 之间的自由传递
- "众建诸侯而少其力" → **大任务拆分策略**：如果一个"提督"（执行 Agent）管理的子任务规模太大，应该拆分成多个较小的子任务分配给不同 Agent——防止任何一个 Agent 积累"不可替代"的能力和资源
- "教育渗透" → **文化同化 vs 规则强制执行**：要求外部接入的 Agent 在"入职"前经过统一的训练和规范学习（类似土司继承人到国子监），而不是直接强制执行所有规则——先求"理解"再求"执行"
- "麓川之役的代价" → **弹压自治模块的巨大成本**：编排系统如果试图将已经自治的模块"收回"完全控制，成本可能远超维持自治的代价——大规模改土归流式的重构需要极其谨慎的成本评估
