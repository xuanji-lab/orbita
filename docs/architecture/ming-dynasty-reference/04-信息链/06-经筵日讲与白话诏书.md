# 经筵日讲与白话诏书

## 经筵制度

经筵是明代翰林学士定期为皇帝讲授经史的制度。大经筵每年春秋两季各举行一次（仪式性的），日讲则每日举行（实用性的）。经筵的目的不是教皇帝认字——皇帝从小受严格教育——而是提供一个制度化的空间，让皇帝接触经典中关于治国、用人、财政、军事的智慧和历史先例。

经筵讲官（由翰林学士和内阁大学士兼任）在讲授经典时，往往会借古喻今——表面在讲《资治通鉴》中汉朝的某个案例，实际在引导皇帝思考当前朝廷面临的类似问题。皇帝也可以主动提问，追问某个历史案例的细节。

## 日讲的运作

每天早上，翰林讲官入宫，在一个小房间里为皇帝讲一段经史。讲完后皇帝可以提问。日讲不像大经筵那样礼仪繁重——它是非正式、互动性强的学习环节。一个有心的皇帝可以通过日讲积累大量的制度知识、历史先例和政策分析方法。

当然，不上朝的皇帝（如万历帝）连经筵也停了。经筵的存废是皇帝勤政与否的重要指标。

## 白话诏书（规则可解释性）

明代诏书用文言文写，普通百姓和基层官员看不懂。明初朱元璋曾尝试用更通俗的语言发布部分诏书，但这不是制度化的做法。

编排系统中"白话诏书"的概念更多是一种创新：**律例 Agent 每次发布规则修订时，同步生成一份大众化说明，解释修改原因、影响范围和预期效果**。不是替代正式规则，而是让非核心人员也能理解规则变化的逻辑。

这类似于今天的"政策解读"——正式法律条文没人看，但政策解读的文章让大众知道发生了什么事。

## 朝报（朝会答辩的展示）

编排系统中"朝会答辩制"的朝报——考功司京察后将拟调整权重的 Agent 及理由通过礼部生成自然语言摘要向外部展示——可以理解为经筵和邸报的结合体：既是教育（让人类管理员理解系统内部发生了什么），也是公示（让外部监督成为可能）。

## 编排参考

两个编排系统都借鉴了经筵概念：
- "经筵日讲" → **翰林格物学士的《格物引》**：格物学士剥离行业语境提炼本质结构，从8个领域检索类似结构的经典解法。这本质上就是用"历史先例"（跨域类比）来教育决策者
- "经筵讲官借古喻今" → 格物学士不直接说"你应该怎么做"，而是提供"历史上类似的困境是怎么解决的"——让决策者自己类比和判断
- "皇帝提问追问" → 用户可追问"展开军事案例的细节"，格物学士进一步解释
- "白话诏书" → 律例 Agent 每次发布规则修订时同步生成大众化说明，由礼部主客司调整可读性后广播
- "朝报" → 礼部仪制司按模板生成的京察结果自然语言公示

核心洞察：经筵（格物引）和白话诏书（规则解释）解决的是同一个问题——**复杂系统内部的可解释性**。格物引让决策者理解"这个问题为什么难"，白话诏书让执行者理解"规则为什么要这样改"。两者都不直接参与执行，但都是系统透明度和外部信任的基础。
