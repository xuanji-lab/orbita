# 国子监与钦天监

## 国子监

国子监是明代的最高学府和教育管理机构。如果说翰林院是精英研究机构，国子监就是大众高等教育机构。

**学生（监生）的来源**：
- **贡生**：从地方学校选拔的优秀生员（秀才中的精英）
- **荫生**：三品以上官员子弟的特权入学
- **例监**：捐资入学的富家子弟（正统以后开放）
- **夷生**：朝鲜、安南、琉球等属国派遣的留学生

**教育内容**：四书五经、《大明律》、《御制大诰》、公文写作、算术。重点培养能直接上岗的行政人才。

**监生的出路**：国子监毕业后（通常4-10年），可参加科举或直接选官。国子监出身的官员被视为"杂流"而非"正途"（进士出身），升迁上限较低。

## 钦天监

钦天监是明代掌管天文观测、历法编制、时间授时和气象预测的机构。它的地位在现代人看来可能不起眼，但在明代它是**承载皇权合法性的核心技术部门**——皇帝被称为"天子"，而钦天监通过天文观测和历法来证明天象与皇权的对应关系。

**核心职能**：
- 编制历书（每年颁行全国的《大统历》）
- 观测天象（日食/月食/彗星）并解释其政治寓意
- 为农业提供节气指导
- 为重大典礼和军事行动择吉日

**钦天监与外国技术**：明末，钦天监的传统计算方法已经出现偏差，耶稣会传教士（如利玛窦、汤若望）带来了欧洲天文学知识，在钦天监内部引发了"中西历法之争"。这场争论最后甚至影响了崇祯朝的政治。

## 太医院

太医院是明代中央医疗和医学教育机构。太医院院使（正五品）掌管全国医政、为皇室提供医疗服务、培养医学人才。太医院分十三科（大方脉/小方脉/妇人/疮疡/针灸/眼科/口齿/接骨/伤寒/咽喉/按摩/祝由/正骨）。郑和下西洋时，太医院派出约180名医官和医士随行——这是古代世界最专业化的远洋医疗保障。

## 编排参考

- "国子监" → **新兵见习期/庶吉士培训**：国子监是常规教育通道(新兵见习)，翰林院庶吉士是精英加速通道(馆阁选士)——编排系统保持了这两条不同的 Agent 成长路径
- "贡生选拔" → **选锋标签的广义应用**：贡生是从地方学校选优(类似从执行 Agent 选优)，选锋是从各部队选精——都是"从基层选拔"的逻辑
- "钦天监" → **模式判定 Agent** 的参照：钦天监通过观测(即读数据)来判断天象，模式判定 Agent 通过任务特征分析来判断走哪种模式——都是"客观数据→判断建议"的结构
- "太医院随郑和" → **御马监随行高风险任务**：太医院派专家跟随舰队(特殊任务配专项支持)，御马监随总控直派高风险任务——都是"常规体系之外的专项强化"
