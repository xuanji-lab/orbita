# D 组 · UI 补齐（3 刀）——定案

> 来源：批次 1 计划（`2026-08-30-批次1-单agent深化.md:209-245`）+ 2026-09-03 grill 会话。
> 参考实现：pi（`docs/reference project/pi/pi-main`）——结论见文末「pi 参考取舍」。

## 已定决定（八问全按推荐案）

1. **D-1 数据源**：`SessionMeta` 加 `recentQueries: string[]`（最近 3 条用户提问首行，
   新→旧），`store.record()` 在用户消息落盘时维护。**shared + store 先行单独一个 PR**，
   UI PR 随后。旧会话无字段 → 空槽，天然兼容。
2. **D-1 上卡规则**：最多 3 张、横排等高；取 `sortSessions` 全局序前 3，排除已归档；
   **从未发过消息的会话（title 为空）不上卡**。
3. **D-1 过渡范围**：三个方向全接同一套 class——首条消息（slogan/卡 220ms 向上淡出 +
   composer 240ms 滑落）、点卡打开（同款正向）、New task 回首页（反向）。
4. **D-2 触发**：`matchMedia` 断点窗口宽 <960px 自动折叠；rail/侧栏上的 `panel-left`
   按钮手动开合；**手动状态不持久化**（与窗口宽度绑定，重启按宽度重算）。
5. **D-2 rail 内容**：自上而下 `panel-left`（展开）→ `plus`（新任务）→ 弹性留白 →
   `archive` → `settings`，贴 `RailButton` 规格（32px 方块 / tooltip 即标签 /
   底部簇）。折叠期间任务列表不可达，要切会话先展开。
6. **D-3 错误呈现**：就地错误态——侧栏列表错误换一行错误行（`triangle-alert` + 原因 +
   重试）；ProvidersView 拆加载 / 空态 / 错误三态；`App.tsx` 的 provider.list 吞错一并拆。
   **侧栏 Workspaces/Tasks 不做加载态**（本地索引毫秒级，只补错误态）。
7. **D-3 空态/加载态**：空会话正文一行 tertiary 提示；历史恢复一行 "Loading…"
   （`loader-circle`）；首页会话卡用规格自带 skeleton。全部复用现有形态，无新组件体系。
8. **推进顺序**：D-3 → D-1（shared → UI）→ D-2。

## 被否决的方案

- **queries 现场读 JSONL**（D-1）：不加字段但 list() 变重、代码更多；record() 本来就
  每条记录原子写 meta，加字段是顺手事。
- **v1 queries 恒空**：卡片剩空壳，视觉价值不成立。
- **只做正向过渡**：回首页是更高频路径，单向会留最生硬的切换。
- **手动折叠状态持久化**：窗口宽度本身不持久化，持久化一个和宽度绑定的状态会打架。
- **rail 上放运行中任务状态点 / hover 浮出 overlay**（D-2）：多一层交互逻辑，
  窄窗折叠是偶发形态非常驻，v1 不值；状态点留作后续增强。
- **D-3 错误走全局红字 Notice**：侧栏问题和正文混在一处，且无重试入口。
- **空会话保持纯空白**：批次 1 计划已把它列为缺口；一行 tertiary 成本可忽略。
- **侧栏列表加加载态**：本地毫秒级读取，加载态是噪音。

## pi 参考取舍

- **可搬**：错误内联不弹模态；单槽位状态条 + 空闲占位防跳动（本组用不上单槽位，
  留待后续）；忙碌时始终留取消入口（已有 Stop）；窄宽度按优先级丢弃信息而非挤压。
- **不适用**：pi 无侧栏折叠实现（其 tui-plan 明列为 future work），D-2 以 DS
  `RailButton` 规格为准；pi 无补间动效，D-1 过渡自建 CSS（token 已备）。
- **无可参考**：pi 无卡片式首页，D-1 卡片完全按 DS `SessionCard` 规格。

## 纪律

- shared 改动单独成 PR（决定 1）；renderer 四层契约同步核对。
- 动效只用 DS 白名单 token：`--transition-layer` / `--transition-composer-exit`，
  `prefers-reduced-motion` 已全局塌缩，无需逐处处理。
- 禁 emoji、禁裸 hex、lucide-only；文案遵守「ellipsis for in-flight, past tense for done」。
