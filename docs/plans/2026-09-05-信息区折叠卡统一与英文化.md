# Plan: 信息区折叠卡统一 + 英文化

日期:2026-09-05 · 分支:theme-black-X · 状态:已拷问定稿,待用户确认开工

## 问题

信息区两类折叠卡不协调,且经拷问拆成两层:

1. **意外不一致(修)**:压缩卡(`CompactedLine`,ChatView.tsx:1440)头部没走 `CollapseRow`
   共用骨架——无 32px 热区、无 hover 淡底、无 radius-sm 裁边、头部不分「label / sub / status」
   三槽;展开体是 `bg-muted` 圆角面板,是全信息区孤例(其它卡都是 hairline 顶线 + 透明)。
2. **有意的语义(留)**:压缩卡上方 `marginTop + borderTop` 界碑(「分段,不是上一轮回复的
   一部分」,代码注释原话)与展开体的 markdown 排版——都不属于「不协调」,不能抹。
3. **文案无层(修)**:renderer 没有任何 i18n 机制,文案散落在组件、纯函数、shared 三层且
   语言随机,同一折叠行出现「read 运行中」。本轮统一为英文;中文等真实需求出现再立项。

pi 参考(docs/reference project/pi/pi-main):pi 的压缩卡也**不**与工具卡混同,与 branch/skill
卡同属 custom message 族(`[compaction]` 标签 + 专属背景),但全族折叠/展开公式一致。
结论:壳可同、族有分——统一的是骨架,保留的是语义。

## 定案(用户逐条裁决)

1. **压缩卡头部并入 CollapseRow 骨架**:32px 热区、hover 淡底、radius-sm、aria-expanded、
   三槽结构(label + status,无 sub)。**无图标**(label 仅文字 `Compacted`)。
2. **界碑保留**:外层 wrapper 维持 `marginTop: --space-4` + `borderTop` hairline +
   `paddingTop: --space-3`——压缩卡与前方内容保持分割线。数据层 `mergeCompactions`
   (session-states.ts:253)不动。
3. **展开体统一到标准**:去掉 `bg-muted` + `radius-md` 面板,改用与 thinking/工具一致的
   hairline 顶线 + 透明 + maxHeight 320 滚动;内部仍是 `MarkdownBlock`(markdown 排版
   保留,不套 mono caption / pre-wrap——从 EXPANDED_BODY 派生一个 markdown 变体常量)。
4. **无展开指示**:不加 chevron、不加文字提示,维持现状。
5. **折叠头文案**:label `Compacted`;status `~N tokens`(无 tokensAfter)/ `N → M tokens`
   (有)。数字沿用 `toLocaleString("en-US")` 千分位 + `tabular-nums`(现状已是)。
   三槽化后 `已压缩 · ` 的「·」连接符废除,分隔职责交给槽间距与颜色分层。
6. **英文化范围 = ChatView 信息区全部用户可见文案**,词条表(Q9 已批准):

   | 位置 | 现状 | 定稿 |
   |---|---|---|
   | 组行动词 bash/read/grep·find/write/edit/ls | 执行/读取/搜索/写入/修改/浏览 | Run / Read / Search / Write / Edit / List |
   | 组行量词 | N 个文件 / N 条命令 / N 处 / N 个目录 / N 次 | N files / N commands / N matches / N directories / N calls |
   | 组行失败 | N 失败 | N failed |
   | write 行数 | N 行 | N lines |
   | 结果状态词 summarizeToolResult | 运行中/失败/无输出/N 行/N 字符 | Running / Failed / No output / N lines / N chars |
   | 思考 label | 思考 | Thinking |
   | 思考时长 | 持续了 N 秒 / N 分 M 秒 | 3s / 1m 05s(去「持续了」) |
   | 工具耗时 | N 秒 / N 分 MM 秒 | 3.2s / 1m 04s |
   | 压缩头 | 已压缩 · … | Compacted · ~N tokens / N → M tokens |
   | 压缩进行态 | 正在压缩上下文… | Compacting context… |
   | 空展开体 PlainToolBody | （等待输出…）/（无输出） | (waiting for output…) / (no output) |
   | 重试行 | 第 x/y 次重试 · N 秒后 / 正在重试… | Retry x/y · in Ns / Retrying… |
   | 分支按钮 | 从当前分支 | Branch from here |

   已是英文、不动:单工具行 label(协议工具名)、Notice 三条、composer placeholder、
   `Responding` / `Loading…` / `Rename task` / 菜单项、`src/shared/permission.ts` 档位标签。
7. **不建 i18n 机制**:各模块文案收敛为模块顶部常量(留将来抽字典的缝,不建字典)。
8. **PR 划分**:单 PR `feat(renderer)`。壳统一与英文化落在同批文件,拆开是两轮验收;
   `src/shared/` 本轮零改动。导出 markdown 的中文(session.ts:262)另立一刀、单独 PR。

## 被否决的方案

- **压缩卡加图标**(候选 scroll-text/layers/history;archive 已有注释排除:与侧栏「归档」
  撞车)——用户否:不要图标,文字足够指认。
- **界碑去掉、完全同款**——我先荐去掉,用户裁决反转:压缩卡要与前面有分割线。界的语义
  (时间插回流分界)赢过视觉齐平。
- **展开体反向统一**(所有卡升级 bg-muted 面板)——否:扩散孤例比收敛它贵。
- **折叠可发现性补指示**(chevron-right→down 旋转,或 pi 式文字 `(ctrl+o to expand)`)
  ——用户否:不要箭头小图标。pi 的文字提示是 TUI 折衷,不照搬。
- **建 strings.ts 字典 / i18n 框架**——否:中文暂无真实需求,AGENTS.md 消费者纪律;
  pi 全英文硬编码先例。只做模块内常量收敛。
- **压缩头 tokens 改 `formatTokens` 紧凑写法**(18.2k,utils/format-tokens.ts)——否:
  那是底栏常显省宽的产物;压缩头是一次性界碑,精确数字符合「把压缩效果摆出来」的注释
  意图,pi 压缩卡同用 `toLocaleString()`。现状已是 en-US 千分位,不动。
- **折叠态内容预览**(pi:bash 末 5 行、grep 15 行、find/ls 20 行)——本次不做,独立工程
  另立 plan。
- **导出 markdown 一并英文化**——否:动 `src/shared/session.ts`,shared 改动单独 PR。
