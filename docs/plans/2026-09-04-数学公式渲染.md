# 数学公式渲染 · 对话区（信息区）

> 分支：`theme-black-X`。需求：用户与 agent 聊天有大量 LaTeX 数学公式，要在对话区正确渲染。
> 方案经 grilling 两轮定案（Q1-Q10 全部有用户拍板），小样（真 KaTeX CDN 页）确认观感后开工。

## 已定的决定

1. **引擎 = KaTeX**（vs MathJax / pi 式自写 Unicode）。决定性理由：react-markdown 的
   rehype 管线是同步纯变换，KaTeX 同步 1~5ms/公式、有官方 rehype-katex 一行接入；
   MathJax 异步队列模型与同步管线相克。MathJax 唯一优势（冷门宏包全覆盖）对 LLM
   输出无意义。`throwOnError: false` 兜底：不认识的命令原地显示源码，可读不破碎。
2. **制式四种全收**：`$…$` / `$$…$$` / `\(...\)` / `\[…\]`（remark-math 默认支持前两种；
   后两种见决定 6 的兜底说明）。参考 pi：`packages/tui/src/latex.ts` + markdown.ts 的
   tokenizer 启发式（金额防误判、流式 pending）。
3. **依赖组合**：`remark-math@6.0.0` + `rehype-katex@7.0.1` + `katex@0.18.5`，全锁精确
   版本。与 react-markdown@10 的 unified 11 管线兼容（peer 无冲突，装前已核）。
4. **流式 pending = pi 式真渲染**（7a）：尾部未闭合定界符先补闭合符喂解析器，公式随
   流式逐字成形；KaTeX 编译不过的瞬间以 `.katex-error` 降级为斜体次级灰（不是报警红）。
   否决了 7b 中性占位（稳但无「公式长出来」的体验）。
5. **安全 = trust: false**：公式永远只是视觉，`\href` 等带行为命令拒绝。与链接拦截
   （ExternalAnchor）同一哲学。
6. **已知边界**：`\(…\)` / `\[…\]` 不是 remark-math 默认制式——v1 不自定义 micromark
   扩展，GPT 系输出以 `$`/`$$` 为主；真遇到再扩展（决定 2 的「全收」以此条为准打折，
   记录在案）。
7. **样式落 token**：`.katex` 颜色 inherit、字号 1.05em、块级居中、错误斜体次级灰。
   KaTeX 自带字体（本地打包，无网络依赖）。

## ponytail 削减（带触发条件）

- **不做按公式源串的渲染缓存**：`MarkdownBlock` 按 text memo 已挡住非流式消息的全部
  重复编译；流式那条消息每帧重编译真卡了再加（`ponytail: memo renderToString by
  source if long math messages measurably chug`）。
- **金额防误判可能零代码**：先实测 remark-math 对 `$5 and $10` 的行为——micromark
  有邻接字符规则，可能天生安全；误判才写降级插件。

## 搭车项（同批做，同属「没渲染」清单）

- **图片拦截**：react-markdown 默认加载远程 `<img>`（隐私洞）——改为永不设 src 的
  占位链接。
- **`<details>` 折叠**：`rehype-raw` + `rehype-sanitize` 白名单只放行
  `details`/`summary`（用户拍板 8a；否决 8b 字面量匹配——安全面靠白名单审计，
  不靠字符串形状运气）。**顺序敏感**：rehypeRaw → rehypeSanitize → rehypeKatex，
  sanitize 在 katex 前（否则剥掉 KaTeX 的 span），且 sanitize 默认 schema 保留
  code 的 language-* class，math 节点能活着走到 katex。

## 不做（理由归档）

- **脚注**：remark-gfm 不含脚注（GitHub 用的是 cmark-gfm 扩展），要另装依赖；
  模型输出命中率极低，失败降级是可读纯文本。触发条件：高频遇到 `[^1]` 再做。
- **扩 shiki 语言池**：静态 import 全进 bundle；未知 fence 已优雅回退。正解是按需
  注册语法，属独立懒加载任务。
- **pi 式自写 LaTeX→Unicode**：那是终端无 DOM 的逼出来的方案，浏览器里没有理由。
