# 会话存储与命名工作区

> 2026-08-25。对应待办 #2「命名工作区容器」。**拆成两刀**：先会话存储（刀 A），再命名工作区（刀 B）。
> 本文只写设计意图、被否决的方案与理由；接口最终形状以 `src/shared/` 里的契约为准。

## 为什么拆

#2 的原话是「命名、多个、**切换时记住各自的会话**」。最后半句需要会话持久化，而今天**完全没有**：
会话只活在 renderer 的 React state 里，刷新即失。反过来先做工作区的话，做完侧栏每个工作区
下面还是空的——没有会话可记。所以顺序只能是先 A 后 B。

## 刀 A：会话存储

### 存什么、存在哪

每个会话两个文件，落在 Electron 的 `userData` 下：

```
sessions/<id>.meta.json    元数据，原子写（临时文件 + rename）
sessions/<id>.jsonl        transcript，只追加，一行一个 TranscriptItem
```

**为什么分两个文件**（被否决：单文件、首行放 meta）：
meta 是**可变**的（标题、updatedAt 会变），transcript 是**只追加**的。把可变记录塞进只追加的日志里，
要么每次改标题就重写整个日志，要么读取时全文扫描找最后一条 meta——两者都在为一个小字段付大代价。
分开之后日志保持纯追加，可变的那一小块走原子写；**列会话只需读 N 个小 meta 文件**，不碰日志。

（也否决了「另建一个 `index.jsonl` 汇总表」：它是第二份真源，会和 meta 文件漂移。）

### 谁来写

**主进程写。** AGENTS.md 的职责划分是「主进程只负责窗口、IPC 与持久化」，
`runtime.ts` 的文件头也自陈「不碰 UI，不碰持久化路径策略」。

主进程手里只有 `progress` 事件，要落盘就得把它归约成 items。
**不写第二份归约逻辑**（guideline §三）——直接用 pi 自带的 `applyTranscriptProgress`，
与 renderer 用的是同一段代码，不是同形状的第二份实现。

### 与 `28-session-storage.md` 的关系

那份文档**不能照抄**，两处明确冲突，都以本分支的真源为准：

| 它写的 | 我们做的 | 依据 |
|---|---|---|
| §12 后端选型 `node:sqlite` | **JSONL 可移植文件** | AGENTS.md「不引入本地数据库」；guideline §四 |
| 三层锚点 / 压缩 / 批红 / 锁院快照 | **不做** | 那是多 agent 的审计机制（「交互审核 Agent」），单 agent 没有消费者 |

可用的是它的 `SessionStore` 接口形状（create / read / update / delete / list）与
「会话按 **workspaceId** 挂」这一条——见下。

## 刀 B：命名工作区

### 唯一一条必须现在就想清楚的事

`28-session-storage.md` 的 `Session` 是按 **`workspaceId`** 挂的，不是按路径。
所以工作区必须有一个**与路径无关的稳定 id**：用户挪个文件夹或改个名，它的会话不该成孤儿。

**更正一个我先前的说法**：我曾说「这条现在花不到十行，事后补要动存量数据」——
**高估了成本**。刀 A 的会话带着 `cwd`（真实路径），刀 B 落地时按 cwd 一次性归属即可，
那一刻路径还是有效的；加字段本身也只是让解析器容忍缺省。

所以按 AGENTS.md「协议加字段是加法，不需要提前占位」，
**刀 A 的 `SessionMeta` 不放 `workspaceId`**，等刀 B 真有工作区列表时再加。
要守住的是「工作区用稳定 id 而不是路径当主键」这条设计，不是提前占一个恒为 null 的字段。

### 不要建的东西

`WorkspaceIsolation` / `WorkspaceBackend`（`07-infrastructure.md §10`）**不建**。
它指的是并行 agent 的隔离执行副本，与本条待办的「用户面命名容器」是两个概念
（见 `docs/ubiquitous-language.md` 的 workspace 词条）。两者是输入关系而非竞争：
`createIsolated(basePath, …)` 里那个 basePath 正是刀 B 要造的东西。
本分支没有 Domain Pack，建它就是提前抽象。

### git 分支显示

设计系统的侧栏参考画了 `🗀 workspace-name  ⎇ main  12`。**本轮不做**——
AGENTS.md 明写本分支不做 git 面板。真要做时，非 git 文件夹的处理设计系统已经给了答案：
`Sidebar.jsx` 是 `{project.branch ? (…) : null}`，**没有分支就什么都不画**，不画占位。
